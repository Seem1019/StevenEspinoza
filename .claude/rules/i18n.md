# i18n

- Locales `es` (default) and `en`; routes always prefixed (`/es/…`, `/en/…`) with identical segments in both languages.
- All visible text — including aria-labels, alt text, meta tags, logs of the showcase, product names — lives in `src/i18n/<lang>/<ns>.json`. Namespaces: `common`, `home`, `showcase`, one per demo slug.
- `useT(lang, ns)` returns `t(key, vars)` and `t.raw<T>(key)`. Missing keys and es/en key mismatches throw at build: never silence them.
- Pages under `src/pages/[lang]/…` export `getStaticPaths = langPaths`.
- Formatting numbers/currency/dates: `Intl` with the page locale.
- Language switching is a soft navigation (`LangSwitch`), preserving query and hash.
- Write both languages natively (not literal translations); keep lengths similar to avoid layout differences.
